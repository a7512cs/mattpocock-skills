# Changesets

你好，歡迎！這個資料夾是由 `@changesets/cli` 自動產生的。它是一個建置工具，適用於多套件的 repo（程式庫）或單一套件的 repo，幫助你為程式碼管理版本並發佈。你可以[在我們的 repository 中](https://github.com/changesets/changesets)找到它的完整說明。

我們在[我們的說明頁面](https://github.com/changesets/changesets/blob/main/docs/common-questions.md)中整理了一份常見問題清單，幫助你開始參與這個專案。
