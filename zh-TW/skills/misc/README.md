# Misc

我留著但很少用的工具，沒有在 plugin（外掛）裡 promoted（推廣）。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：設定 Claude Code hook，在危險的 git 指令（push、reset --hard、clean 等）執行之前擋下它們。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：把測試檔從 `as` 型別斷言遷移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：建立練習題的目錄結構，包含章節、題目、解答和說明。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：設定 Husky pre-commit hook，搭配 lint-staged、Prettier、型別檢查和測試。
