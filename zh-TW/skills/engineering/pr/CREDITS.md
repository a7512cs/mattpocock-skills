# 致謝 (Credits)

**Summary** 段落的視覺化選單（pseudocode（虛擬碼）、呼叫樹、元件樹、檔案樹、Mermaid、diff（差異））和它的擺放指引，來自 [Dex Horthy](https://github.com/dexhorthy) 的 [`show-me`](https://github.com/humanlayer/humanlayer) skill（技能），幾乎逐字照搬，並把目標從即時對話改成 diff。`pr` 並不把 `show-me` 當成 skill 來依賴（它不屬於這個 repo（儲存庫），而且硬性依賴會讓單獨安裝壞掉），所以內容是複製進來，而不是用指標指過去；這個檔案就是原本依賴關係會帶有的署名。
