> **description 中譯：** 對照可信度高的 primary source（第一手資料）調查一個問題，並把發現寫成 repo（程式碼倉庫）裡的一個 Markdown 檔。當使用者想研究某個主題、蒐集文件或 API 的事實，或把閱讀的苦工交給 background agent（在背景執行的 agent）時使用。

啟動一個 **background agent** 來做研究，這樣它在讀資料時你可以繼續工作。

它的工作：

1. 對照 **primary source**（官方文件、原始碼、規格、第一方 API）調查問題，而不是看別人對它們的二手整理。把每個說法都追溯回擁有它的那個來源。
2. 把發現寫進單一個 Markdown 檔，每個說法都註明來源。
3. 把它存在 repo 已經放這類筆記的地方；符合現有慣例，如果沒有慣例，就放在合理的地方，並說明放在哪裡。
